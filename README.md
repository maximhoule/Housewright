# Housewright

Design a house in Nova Scotia room by room: floor plans, 3D, NBC Part 9 checks, energy tier estimate, structure screening, electrical and heating layout, materials list, itemized budget, permit drawings and a builder package.

**Open the app:** https://maximhoule.github.io/Housewright/

## Install on your phone
1. Open the link above in Chrome (Android) or Safari (iPhone).
2. Chrome: menu ⋮ → **Add to Home screen** → Install. Safari: Share → **Add to Home Screen**.
3. It opens full screen like an app and works offline.

## Updates
Every change pushed to this repo is published automatically by GitHub Pages. The app checks for a new version each time it opens and shows a message when one is ready; close and reopen to use it.

## Your data
Your design is saved on your phone (browser storage), never in this repo. To move a house between this app and the Claude version: ⋯ → **Copy project data** in one, ⋯ → **Paste project data** in the other.

## Claude features
The room and house chats, inspiration photos and AI helpers need Claude. In this app, add your own Anthropic API key under ⋯ → **Claude on this phone**; it stays on the device and each request is billed to that key. Everything else works without it.
